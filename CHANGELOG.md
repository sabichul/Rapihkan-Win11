# Changelog

## 1.2.0

- Added a portable WinForms desktop window; no installer or shortcut is required.
- Added local action history, Quarantine listing and restore, and cache-size review for common browser and developer tools.
- Added selected-file organization preview, custom organization categories, and user-managed excluded paths.
- Added a local HTML dashboard report and native Windows completion notifications.
- Added an opt-in audit-only weekly schedule. It creates reports but never moves files.
- Added GitHub Actions validation, ZIP build, checksum generation, and tag-based releases.

## 1.1.0

- Renamed the user-facing product to Rapihkan Win11.
- Added an English interactive menu and progress status for every module.
- Added reversible actions for temporary files and organization plans.
- Require three `YES` confirmations before moving files.
- Added the MIT license, contribution guide, `.gitignore`, and Markdown lint configuration.

## 1.0.0

- Added system, storage, performance, and Windows-health checks.
- Added temporary-file and duplicate-file candidate discovery.
- Added quarantine and restore primitives for individual file operations.
- Added local JSON, CSV, Markdown, and HTML report export.
