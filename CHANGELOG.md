# Changelog

## 1.1.0

- Renamed the user-facing product to Rapihkan Win11.
- Added an English interactive menu and progress status for every module.
- Added reversible actions for temporary files and organization plans.
- Require three `YES` confirmations before moving files.
- Added the MIT license, contribution guide, `.gitignore`, and Markdown lint configuration.

## 1.0.0

- Added system, storage, performance, and Windows-health checks.
- Added temporary-file and duplicate-file candidate discovery.
- Added quarantine and restore primitives for individual file operations.
- Added local JSON, CSV, Markdown, and HTML report export.
